# Le Huu Luan — Balanced Portfolio

This version is designed to feel like a mix of:
- a real developer portfolio
- a modern polished portfolio

## Direction
Compared to the previous clean version, this build adds subtle effects:
- scroll progress bar
- reveal-on-scroll
- active nav highlighting
- light/dark toggle
- soft glass panels
- hover lift on cards
- floating portrait chips
- understated gradient accents

The goal is to feel modern, but not overly "AI-template".
